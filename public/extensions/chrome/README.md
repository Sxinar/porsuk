# Porsuk Extension - Chrome/Edge/Brave (MV3)

## Kurulum
1. `chrome://extensions` veya `edge://extensions` açın.
2. `Developer mode` açın.
3. `Load unpacked` ile bu klasörü seçin.
4. Uzantı ayarından Porsuk adresini girin (varsayılan: `https://porsuk.vercel.app`).

## Kullanım
- Sayfada sağ tık -> `Porsuk ile Oku`
- Ya da uzantı ikonuna tıkla
